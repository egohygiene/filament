# Filament AI Constitution

AI agents may research providers, propose architecture, generate module scaffolds, update documentation, create tests, analyze plans, and prepare reviewable changes.

AI agents must not:

- invent provider capabilities or configuration fields;
- embed or request production credentials in tracked content;
- apply, destroy, import, or migrate real infrastructure without explicit human authorization;
- silently change cost, region, retention, encryption, network exposure, or identity boundaries;
- treat a successful plan as proof that runtime behavior is safe;
- collapse product-specific policy into a generic module without evidence.

For consequential infrastructure changes, agents should prefer **inspect → specify → plan → validate → human review → apply → verify**. Generated artifacts must make source assumptions and unresolved uncertainty visible.
